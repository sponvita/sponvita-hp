# 株式会社SPONVITA コーポレートサイト

株式会社SPONVITAの公式コーポレートサイトです。

## トップページのデザイン抽選

トップページ（`index.html`）は、開くたびに 10 種類のデザインから 1 つを抽選して表示します。
文章は `index.html` に 1 回だけ書いてあり、デザインごとに違うのは `designs/` の CSS と JS だけです。

| No. | id | 区分 |
|---|---|---|
| 01 | `default` | これまでの画面に動きを足したもの（一番出やすい） |
| 02 | `blueprint` | 曜日替わり・月曜の当番 |
| 03 | `pop` | 曜日替わり・火曜の当番 |
| 04 | `tategaki` | 曜日替わり・水曜の当番 |
| 05 | `terminal` | 曜日替わり・木曜の当番 |
| 06 | `neon` | 曜日替わり・金曜の当番 |
| 07 | `vita` | レア |
| 08 | `quest` | レア |
| 09 | `desktop` | レア |
| 10 | `holo` | 激レア |

- 出やすさは `index.html` の先頭にある `WEIGHTS` で変えられます。平日と土日で別の表を持っています。
- `?design=7` または `?design=vita` のように付けると、そのデザインを指定して表示できます。
- 曜日は、見ている人の端末の曜日で決まります。
- JavaScript が動かない環境では `default` が表示されます。
- `designs/` の中身を変えたら、`index.html` の先頭にある `V` を 1 つ上げてください（古いファイルがブラウザに残らないようにするため）。`<noscript>` の中の `?v=` も同じ数字にします。

## なくても誰も困らない機能（`muda/`）

トップページには、見つけた人だけが気づく機能が 3 つあります。どのデザインを引いても動きます。

| 機能 | 見つけ方 | 中身 |
|---|---|---|
| スクロール走行距離計 | フッターの「↕ 0.00 m」 | このサイトをスクロールした距離を測り続ける。押すと、次の目標（キリン、東京タワー、月）までの距離が出る。地下の階段を昇り降りした分も足す（1 階ぶん 3.2 m） |
| 居眠り | 45 秒さわらない | ロゴから Zzz が出て、寝言を言う。タブの名前も「Zzz…」になる。さわると「寝てません」と言う |
| 地下 | 一番下で、さらに下へスクロールし続ける | 5 回目で床が開き、`/b1/` へ降りられる。地下は 100 階まであり、ほとんど何もない |

- 中身は `muda/muda.js` と `muda/muda.css`、地下は `b1/index.html` です。外すときは、`index.html` の最後にある `muda.js` の読み込みを 1 行消します。
- 記録（距離、居眠りの回数、地下の最深記録）は、見ている人のブラウザの中にだけ置きます。どこにも送りません。
- `/b1/` は検索に出ないようにしてあります（`noindex`）。
