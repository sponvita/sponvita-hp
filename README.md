# 株式会社SPONVITA コーポレートサイト

株式会社SPONVITAの公式コーポレートサイトです。

## トップページのデザイン抽選

トップページ（`index.html`）は、開くたびに 10 種類のデザインから 1 つを抽選して表示します。
文章は `index.html` に 1 回だけ書いてあり、デザインごとに違うのは `designs/` の CSS と JS だけです。

| No. | id | 区分 |
|---|---|---|
| 01 | `default` | これまでの画面（一番出やすい） |
| 02 | `blueprint` | 曜日替わり・月曜の当番 |
| 03 | `pop` | 曜日替わり・火曜の当番 |
| 04 | `tategaki` | 曜日替わり・水曜の当番 |
| 05 | `terminal` | 曜日替わり・木曜の当番 |
| 06 | `neon` | 曜日替わり・金曜の当番 |
| 07 | `vita` | レア |
| 08 | `quest` | レア |
| 09 | `desktop` | レア |
| 10 | `holo` | 激レア |

- 出やすさは `index.html` の先頭にある `WEIGHTS` で変えられます。平日と土日で別の表を持っています。
- `?design=7` または `?design=vita` のように付けると、そのデザインを指定して表示できます。
- 曜日は、見ている人の端末の曜日で決まります。
- JavaScript が動かない環境では `default` が表示されます。
