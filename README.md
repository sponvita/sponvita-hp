# 株式会社SPONVITA コーポレートサイト

株式会社SPONVITAの公式コーポレートサイトです。

## トップページのデザイン抽選

トップページ（`index.html`）は、開くたびに 10 種類のデザインから 1 つを抽選して表示します。
文章は `index.html` に 1 回だけ書いてあり、デザインごとに違うのは `designs/` の CSS と JS だけです。

| No. | id | 区分 |
|---|---|---|
| 01 | `default` | これまでの画面に動きを足したもの（一番出やすい） |
| 02 | `blueprint` | 曜日替わり・月曜の当番 |
| 03 | `pop` | 曜日替わり・火曜の当番 |
| 04 | `tategaki` | 曜日替わり・水曜の当番 |
| 05 | `terminal` | 曜日替わり・木曜の当番 |
| 06 | `neon` | 曜日替わり・金曜の当番 |
| 07 | `vita` | レア |
| 08 | `quest` | レア |
| 09 | `desktop` | レア |
| 10 | `holo` | 激レア |

- 出やすさは `index.html` の先頭にある `WEIGHTS` で変えられます。平日と土日で別の表を持っています。
- `?design=7` または `?design=vita` のように付けると、そのデザインを指定して表示できます。
- 曜日は、見ている人の端末の曜日で決まります。
- JavaScript が動かない環境では `default` が表示されます。
- `designs/` の中身を変えたら、`index.html` の先頭にある `V` を 1 つ上げてください（古いファイルがブラウザに残らないようにするため）。`<noscript>` の中の `?v=` も同じ数字にします。

## なくても誰も困らない機能（`muda/`）

トップページには、見つけた人だけが気づく機能があります。どのデザインを引いても動きます。

| 機能 | 見つけ方 | 中身 |
|---|---|---|
| スクロール走行距離計 | フッターの「↕ 0.00 m」 | このサイトをスクロールした距離を測り続ける。押すと、次の目標（キリン、東京タワー、月）までの距離が出る。地下と屋上の階段を昇り降りした分も足す（1 階ぶん 3.2 m） |
| 居眠り | 45 秒さわらない | ロゴから Zzz が出て、寝言を言う。タブの名前も「Zzz…」になる。さわると「寝てません」と言う |
| 地下 | 一番下で、さらに下へスクロールし続ける | 5 回目で床が開き、`/b1/` へ降りられる。地下は 100 階まであり、ほとんど何もない |
| 屋上 | 一番上で、さらに上へスクロールし続ける | 5 回目で天井が開き、`/rf/` へ昇れる。屋上の上に屋上が 100 階まである。空の色・太陽と月・星は端末の時刻で変わり、建物・山・雲は階で変わる |
| 謎の集計 | 地下と屋上の 10 階から先 | たまに、壁や手すりに集計が貼ってある。地下はトップページの句読点や文字の内訳など 5 種類、屋上は見晴らしや月齢など 5 種類 |
| 印刷証明書 | トップページを印刷する | 1 枚目に「印刷したことの証明書」が付く。2 枚目からは、いつものページがそのまま出る |

- 中身は `muda/muda.js` と `muda/muda.css`、地下は `b1/index.html`、屋上は `rf/index.html`、地下と屋上で共通の部品は `muda/stairs.js` です。外すときは、`index.html` の最後にある `muda.js` の読み込みを 1 行消します（入口と証明書がなくなります）。
- 記録（距離、居眠りの回数、地下と屋上の記録、印刷の回数）は、見ている人のブラウザの中にだけ置きます。どこにも送りません。
- 地下と屋上は `noindex` で、`sitemap.xml` にも入れていません。
- 確認用の指定：`/rf/?f=60` で階、`/rf/?t=18.5` で時刻（18 時半の空）、`/b1/?f=12&stat=1` や `/rf/?f=12&stat=3` で集計（1〜5）を指定して出せます。
- `muda/muda.js` を変えたら `index.html` の読み込みの `?v=` を、`muda/muda.css` を変えたら `muda.js` の先頭の `V` を、`muda/stairs.js` を変えたら `b1/` と `rf/` の読み込みの `?v=` を、それぞれ 1 つ上げます。
